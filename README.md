# UCCC

Howdy?!

Easy to use. Just copy and past the <bod> HTML code to the place where your ads should be.

It will show a PP(Privacy Policy) alert! or UCCC(Universal Cookies Common Confirmation).

Somewhat like the following warning style:

> [!WARNING]
> Urgent info that needs immediate user attention to avoid problems.

IMPORTANT:
Replace:
1. "YOUR_PUBLISHER_ID" with your adsens PUBLISHER_ID.
2. "YOUR_AD_UNIT_ID" with your adsens UNIT_ID.
3. TOS link with your website/blog TOS link.
4. PP link with your website/blog PP link.
